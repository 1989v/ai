# Diet Criteria

## 1. 증거가 먼저
제거 후보는 **사용 증거**로 정한다. 측정 명령은 `skills/diet/SKILL.md` §1. 증거 출처:
- 세션 기록(`~/.claude/projects/<project>/*.jsonl`, 보존 기간 안)의 Skill/Agent 호출 수, 사용자가 직접 친 `/hns:` 수
- `/skill-doctor`(미사용 스킬 + 컨텍스트 비용), `/doctor`(CLAUDE.md 트림 제안), `/context`(실제 로드 파일)
- 프로젝트에 남은 산출물(스펙 폴더 구조·회고·리포트가 실제로 생성됐는가)

## 2. CLAUDE.md (상한 200줄)
| 분류 | 기준 | 처리 |
|---|---|---|
| always | 매 세션 필요(빌드 명령·핵심 원칙·규칙 위치) | 유지 |
| on-demand | 특정 경로·작업에서만 필요 | `.claude/rules/` + `paths:` 또는 스킬로 |
| derivable | 코드·git 에서 파생 가능(모듈 목록·최근 변경) | 삭제 |
| duplicate | 다른 문서에 이미 있음 | 포인터만 |

코드 블록 10줄 이상·표 5행 이상은 on-demand 후보.

## 3. 규칙·스킬·에이전트·훅
| # | 기준 | 신호 | 처리 |
|---|---|---|---|
| 1 | 미사용 | 보존 기간 전체 호출 0 | 후보 |
| 2 | 플랫폼 중복 | 경로 규칙·워크트리·컴팩션·메모리·평가를 다시 구현 | 제거, 플랫폼 기능으로 |
| 3 | 모델 중복 | 규칙 없이도 올바르게 동작(샘플 3회) | 후보 |
| 4 | 상위 규칙 포함 | 다른 규칙이 같은 범위 | 통합 |
| 5 | 스택 무관 | 현재 프로젝트와 무관 | 제거 |
| 6 | 실행 불가 | 스키마·경로가 실제와 다름(과거 훅 템플릿처럼) | 즉시 제거 또는 실제 스키마로 재작성 |

## 4. 절차
후보 목록 → 사용자 승인 → 실행 → `docs/changelog/harness-changelog.md` 기록 → 문제 시 `evolve` 로 복원.
