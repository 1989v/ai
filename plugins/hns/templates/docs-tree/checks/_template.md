# Code Checks — {{scope}}

> **흉터 목록.** 실제로 터진 결함 하나가 한 줄이 된다. 컨벤션("이렇게 쓴다")이 아니라
> 재발 방지("여기서 깨졌다")다 — 규범은 `docs/conventions/` 에 둔다.
>
> 입구는 `/hns:code-check` 하나. 직접 편집하지 않는다(심판·중복 확인·출처 규약이 그 스킬에 있다).
> 읽는 곳 둘: `hns:implementer` 가 코딩 전 자기대조로, 구현 후 리뷰가 적대적 사냥 영역으로.
>
> 형식: `- [ ] **핵심 요점** — 왜 위험한지 / 어떻게 해야 하는지. (출처: YYYY-MM-DD, 근거)`
> 출처 괄호는 항목과 함께 움직인다. 분량 상한(soft) 140줄 — 길면 안 읽힌다.
