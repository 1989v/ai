# 검수 체크리스트 — 결과를 열어서 항목별로 본다

「생성이 끝났다」와 「쓸 수 있다」는 다르다. 단계마다 결과 파일을 **열어**(이미지는 `Read`, 영상은 아래 방법)
항목을 하나씩 ○/× 로 적고 `job.md` 에 남긴다. 수치가 초록불이어도 그림은 봐야 결함이 보인다.

## 공통 (이미지·영상 프레임)

| # | 항목 | 보는 법 |
|---|---|---|
| 1 | 손가락 5개 · 발가락 5개 · 손이 뭉개지지 않음 | 손이 보이는 프레임을 확대해 센다 |
| 2 | 팔·다리 길이가 입력(앵커)과 같은 비율 | 앵커와 나란히 두고 머리 크기 대비 다리 길이를 비교 |
| 3 | 얼굴이 같은 사람 · 나이대 유지 | 눈매·코·입 위치, 얼굴형. 「닮았다」가 아니라 「같은 사람」 |
| 4 | 요구한 프레이밍 (전신 / 3면 / 비율) | 머리·발끝이 잘리지 않았는가, 캔버스 비율 |
| 5 | 배경 요구 (검정 단색 / 회색 / 빈 영역) | 그림자·바닥·그라데이션이 끼지 않았는가 |
| 6 | 텍스트·로고·워터마크 없음 | 모서리와 의상 위 글자 |
| 7 | 인물·캐릭터 수 = 1 (또는 요구한 수) | 배경의 실루엣까지 |
| 8 | 원본에 없는 소품·의상·헤어 변화 없음 | 앵커와 대조 |

## 영상 추가

| # | 항목 |
|---|---|
| 9 | 첫 1초가 IMAGE 1 · 마지막 정지 포즈가 IMAGE 2 |
| 10 | 중간에 얼굴이 딴 사람이 되는 구간 없음 · 팔다리가 늘어나는 구간 없음 |
| 11 | 변신이 순간 교체가 아니라 연속 전환 |
| 12 | 마지막 포즈를 잠깐 **유지**하고 끝남 |
| 13 | 길이·해상도가 견적한 것과 같음 (`mdls`/`sips` 로 잰 값) |

영상 프레임 보기: `ffmpeg` 가 있으면 `ffmpeg -i outputs/video-1.mp4 -vf fps=2 outputs/frames/%03d.png` 로 뽑아 처음·중간·끝을 `Read`.
없으면 `qlmanage -t -s 1080 -o outputs/frames outputs/video-1.mp4` 로 첫 프레임만 얻고, 나머지는 사용자가 재생해 9~12 를 확인한다
(`brew install ffmpeg` 한 번이면 그 뒤로는 자동).

## 판정

- 전 항목 ○ → PASS. 사용자에게 파일과 표를 보이고 OK 를 받는다.
- × 가 있으면 REGEN — **바꿀 것 하나**를 정한다(장르 파일의 「자주 나는 실패와 손잡이」). 같은 프롬프트로 다시 돌리는 것은
  재시도가 아니라 운에 거는 것이다. 두 번 바꿔도 안 되면 앞 단계(앵커)로 돌아간다.
- 재생성 횟수는 승인 횟수 안에서만. 다 쓰면 훅이 막는다 → 견적·승인부터 다시.
