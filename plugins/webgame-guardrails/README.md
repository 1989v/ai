# webgame-guardrails

브라우저 게임(캔버스 · WebGL)의 **품질 게이트와 장르별 수치 규격** 모음.

운영 중인 파이프라인에서 뽑았다 — 캔버스 게임 74종과 Unity WebGL 1종을 만들면서
**실제로 반려당한 것들**만 규칙이 됐다. 각 항목에 그렇게 만든 사건이 함께 적혀 있다.

## 들어 있는 것

- **가드레일 G1~G7** — 화면 축척, 한국어 명명, 화면 흔들림, 어중간한 3D 금지,
  모바일 1순위, 벤치마크 규모, 프레임 예산·발열
- **장르 프리셋 11종** — 벨트스크롤 / 생존건설 / 쿼터뷰 파밍 / 종스크롤 슈팅 /
  캐주얼 / 격자 퍼즐 / 정렬 퍼즐 / 네모로직 / 파티 도구 / 협동 디펜스 / 그리기 퍼즐.
  장르마다 해상도·조작·콘텐츠 깊이를 수치로 고정한다

## 왜 이런 게 필요한가

게임을 만들다 보면 **미달을 스스로 못 본다.** "예쁘게 나왔다" 와 "벤치마크 급이다" 는
다른 판정인데, 만든 사람에게는 같아 보인다. 이 문서는 그 차이를 **수치로 가른다** —
캐릭터가 화면의 몇 분의 일인지, 폰에서 몇 CSS px 인지, 30분 뒤 기기가 얼마나 뜨거운지.

가장 자주 실패한 축은 **모바일**이었고, 두 번째가 **규모**였다.

## 한계

- 플랫폼 연동(랭킹·세이브·가상패드)은 **빠져 있다.** 원본에는 있지만 자체 인프라에 묶여 있다
- 정적 검사 스크립트도 빠져 있다. 규칙은 문서로만 있고, **문서에만 적힌 규격은 지켜지지 않는다** —
  자기 프로젝트의 게이트로 옮기는 것은 각자의 몫이다
- 원본이 계속 바뀌므로 이 사본은 스냅샷이고 자동 동기화되지 않는다
